Emergency Hamburg API

Reference documentation for integrating the Roblox module and dashboard with the Emergency Hamburg platform.

Getting Started

Welcome to the Emergency Hamburg API documentation. This platform allows Owner and Admin users to seamlessly manage Roblox servers.

Authentication

Authentication is required for all API endpoints.

  • Roblox Servers: Use Bearer Token authentication.
  • Dashboard: OAuth flow is used to authenticate users.
Authorization: Bearer YOUR_TOKEN_HERE

Server Endpoints

Manage and monitor your server states.

MethodEndpointDescription
POST/api/server/heartbeatSend server heartbeat.
POST/api/server/metaUpdate server metadata.
GET/api/server/adminsList server Admins and Owners.
POST/api/server/shutdownInitiate server shutdown.

Player Tracking

Track player activities and states.

MethodEndpointDescription
POST/api/player/joinLog a player joining.
POST/api/player/leaveLog a player leaving.
POST/api/player/actionLog actions like shots, robbery, teamchange, etc.

Punishments

Manage player punishments. Only accessible by Owner and Admin.

MethodEndpointDescription
POST/api/punish/banBan a player.
POST/api/punish/unbanUnban a player.
POST/api/punish/kickKick a player.
POST/api/punish/warnWarn a player.

Audit Logs

Retrieve logs of actions performed by Owners and Admins.

MethodEndpointDescription
GET/api/logsGet recent audit logs.

Server Keys / API Key Management

Manage authentication keys for your servers.

MethodEndpointDescription
GET/api/keysList API keys.
POST/api/keys/generateGenerate a new API key.
DELETE/api/keys/{id}Revoke an API key.

Chat

Monitor and interface with the in-game chat.

MethodEndpointDescription
POST/api/chat/messageLog a chat message.

Configuration

Manage the config.json fields remotely.

MethodEndpointDescription
GET/api/configGet current configuration.
POST/api/config/updateUpdate configuration values.

Roblox Module Setup

Instructions for setting up the in-game Roblox module.

  1. Place the provided module script into ServerScriptService.
  2. Set your API key in the configuration section of the script.
  3. Ensure HTTP requests are enabled in game settings.

Never commit your API token to a public place — regenerate it immediately if it's exposed.

local APIToken = "YOUR_API_TOKEN_HERE"
local Endpoint = "https://your-domain.com/api"
