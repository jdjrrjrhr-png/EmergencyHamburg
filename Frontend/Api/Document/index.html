API Documentation

The Emergency Hamburg API provides real-time player tracking, moderation commands, audit logging, and Discord integration for authorized servers. All endpoints require authentication.

Introduction
All API requests must be sent to https://api-production-59e1.up.railway.app. Roblox server requests use the ApiToken Bearer header. Dashboard actions are authenticated via Roblox OAuth session.

Two categories of callers exist: Roblox servers (authenticated with Bearer token) and admin dashboard users (authenticated via Roblox OAuth). The dashboard handles the OAuth flow automatically.

Authentication
ANY Authorization: Bearer <ApiToken> Roblox server requests

Every request from the Roblox server must include this header. The ApiToken is set in your server's .env file and inside the Lua module.

JavaScript
const response = await fetch("https://api-production-59e1.up.railway.app/api/tracking/join", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer YOUR_API_TOKEN"
  },
  body: JSON.stringify({ userId: 123456789, username: "PlayerName" })
});

Not a developer?

You don't need to write a single line of code. Our dashboard gives you every tool this API offers — moderation, audit logs, player map, and chat — through a clean, easy-to-use interface with more features than the raw API. It is significantly easier and has more features than calling these endpoints manually.

Head to the dashboard — it's faster, cleaner, and requires no technical knowledge.

Player Join / Leave
POST /api/tracking/join Report player joined server

Called by the Roblox server when a player joins. Adds the player to global tracking and pushes a player_added audit log entry.

const res = await fetch("/api/tracking/join", {
  method: "POST",
  headers: { "Content-Type": "application/json", "Authorization": "Bearer TOKEN" },

    username: "PlayerName",

Ban / Unban
Bans are stored in-memory on the API and replicated to Roblox DataStore via the ban command. A ban with duration: -1 is permanent. Duration is always in seconds.
POST /api/punishments/ban Ban a player

Body Parameters

NameTypeRequiredDescription
serverCodestringoptionalLive server to issue kick command in
bannedUserNamestringrequiredUsername of player to ban
bannedUserIdnumberrequiredUser ID of player to ban
responsibleIdnumberrequiredAdmin's user ID (senderId)
responsibleUsernamestringrequiredAdmin's username
durationnumberrequiredSeconds, or -1 for permanent
reasonstringoptionalBan reason
JavaScript — Ban for 24 hours
const res = await fetch("/api/punishments/ban", {
  method: "POST",
  headers: { "Content-Type": "application/json", "Authorization": "Bearer TOKEN" },
  body: JSON.stringify({
    serverCode: "b1zw-z1ld-24s1-dm23",
    bannedUserName: "BadPlayer",
    bannedUserId: 987654321,
    responsibleId: 123456789,
    responsibleUsername: "AdminName",
    duration: 86400, // 24 hours in seconds
    reason: "RDM / Exploiting"
  })
});
const { caseId } = await res.json();
// Store caseId for future unban reference

// Issue warn
const warnRes = await fetch("/api/punishments/warn", {
  method: "POST",
  headers: { "Content-Type": "application/json", "Authorization": "Bearer TOKEN" },

Heartbeat
POST /api/servers/:serverCode/heartbeat Send live player state

The core loop. Called every 2 seconds by the Roblox server. Returns pending commands for the server to execute.

JavaScript
const res = await fetch(`/api/servers/${serverCode}/heartbeat`, {
  method: "POST",
  headers: { "Content-Type": "application/json", "Authorization": "Bearer TOKEN" },
  body: JSON.stringify({
    playersList: [
      { name: "Player1", userId: 111, team: "Police", timeInGame: 300, isFrozen: false, inVehicle: true, pos: { x: 120, z: -40 } }
    ]
  })
});
const { commands } = await res.json();
// Process each command: { action, target, targetId, reason, duration, senderName }

Map & Positions
POST /api/servers/:serverCode/positions Stream player positions for top-down map

Only send this if at least one admin is watching the dashboard for this server AND the server has ≥ 10 players. Send every 5 seconds. Only include players who moved ≥ 7 studs since the last packet.

Map normalization algorithm
// Convert game coordinates to map image percentages
function worldToMap(x, z, bounds) {
  const left = ((x - bounds.X_min) / (bounds.X_max - bounds.X_min)) * 100;
  const top  = ((z - bounds.Z_min) / (bounds.Z_max - bounds.Z_min)) * 100;
  return { left, top }; // Use as CSS left% and top% on the image
}

// Example
const bounds = { X_min: -800, X_max: 800, Z_min: -800, Z_max: 800 };
const pos = worldToMap(320, -120, bounds);
// → { left: 70, top: 42.5 }

Roblox Module Reference

Place ShieldModule.lua in ServerScriptService. Require it and call functions to log events and issue commands. All functions are non-blocking (wrapped in task.spawn).

Lua — Module usage
local Shield = require(game.ServerScriptService.ShieldModule)

-- Reporting (Roblox-server-only, no dashboard command executed)
Shield.ShotsFired(shooterName, shooterUserId, targetName, targetUserId, weapon, posX, posZ)
Shield.SetRobbery(suspects, robberyName, robberyType, startedAt)
Shield.SetWanted(playerName, playerUserId, stars, reason, crimes)
Shield.PlayerTeamChanged(playerName, playerUserId, oldTeam, newTeam, xpGiven)
Shield.PhoneCall(playerName, playerUserId, posX, posZ, forTeam, message)
Shield.PlayerDown(playerName, playerUserId, playerTeam, killerName, killerId, weaponName, posX, posZ)

-- Punishments (logs + queues Roblox command)
Shield.Ban(bannedName, bannedUserId, responsibleName, responsibleId, duration, reason)
Shield.Unban(userId, responsibleName, responsibleId, reason)
Shield.Kick(targetName, targetId, responsibleName, responsibleId, reason)
Shield.Warn(targetName, targetId, responsibleName, responsibleId, reason, expireSeconds)
Shield.Unwarn(targetName, targetId, caseId)
Shield.Warns(targetName, targetId) -- returns table of warn records
Shield.FreezeToggle(targetName, targetId, responsibleName, responsibleId)
Shield.Bring(targetName, targetId, responsibleName, responsibleId)
Shield.To(targetName, targetId, responsibleName, responsibleId)

-- Side commands (meta / info only, no punishment executed)
Shield.ServerShutdown(responsibleName, responsibleId)
Shield.PlayerSetInventory(playerName, playerUserId, inventory)
Shield.UpdateAdmins(adminIdsArray)
Shield.SetServerOwner(userId)
Shield.ServerSetName(newName)
Shield.ServerSetJoinCode(newCode)
Shield.Addlocation(locationName, positionsArray, text)
Shield.Message(toWho, message) -- @everyone | @me | username
