API Documentation

This covers the punishment commands (ban, kick, warn, freeze) and the audit log events they and player activity generate. All command endpoints require authentication — see the note at the top of the Commands section.

Base URL: https://api-production-59e1.up.railway.app. Every command below accepts a request either from the dashboard (a logged-in admin) or directly from a Roblox server — a Roblox-originated call sends Authorization: Bearer <API_TOKEN>, the fixed shared secret configured on your backend and inside ShieldModule.lua. This token is never shown in the dashboard and never rotates on its own.
Never share the API_TOKEN. It authenticates every Roblox server on your backend — anyone holding it can issue any command below on any server. If you suspect it's leaked, change it in your backend's .env and in ShieldModule.lua together. (This is separate from a server's individual API Key, which just identifies which server a heartbeat belongs to and is shown only to that server's owner in the dashboard's Side Menu.)
Triggers & Logging

Every one of these actions is written to the server's persistent Audit Log (visible in the dashboard's Side Menu → Audit Log, and via GET /api/audit/:serverCode), whether triggered from the dashboard or from Roblox itself. Punishment entries always carry a Case ID and the Responsible ID (the acting admin's user ID) so any action can be traced back and, where applicable, reversed.

Ban / Unban
Bans are stored in-memory on the API and replicated to Roblox DataStore via the ban command. A ban with duration: -1 is permanent. Duration is always in seconds.
POST /api/punishments/ban Ban a player

Body Parameters

NameTypeRequiredDescription
serverCodestringoptionalLive server to issue kick command in
bannedUserNamestringrequiredUsername of player to ban
bannedUserIdnumberrequiredUser ID of player to ban
responsibleIdnumberrequiredAdmin's user ID (senderId)
responsibleUsernamestringrequiredAdmin's username
durationnumberrequiredSeconds, or -1 for permanent
reasonstringoptionalBan reason
JavaScript — Ban for 24 hours
const res = await fetch("/api/punishments/ban", {
  method: "POST",
  headers: { "Content-Type": "application/json", "Authorization": "Bearer TOKEN" },
  body: JSON.stringify({
    serverCode: "b1zw-z1ld-24s1-dm23",
    bannedUserName: "BadPlayer",
    bannedUserId: 987654321,
    responsibleId: 123456789,
    responsibleUsername: "AdminName",
    duration: 86400, // 24 hours in seconds
    reason: "RDM / Exploiting"
  })
});
const { caseId } = await res.json();
// Store caseId for future unban reference

Warn / Unwarn
POST /api/punishments/warn Warn a player

Warn case IDs are 6-character alphanumeric strings, e.g. aB3xZ9. Pass them to /unwarn to remove specific warnings.

NameTypeRequired

JavaScript — Warn and fetch all warns
// Issue warn
const warnRes = await fetch("/api/punishments/warn", {
  method: "POST",
  headers: { "Content-Type": "application/json", "Authorization": "Bearer TOKEN" },
  body: JSON.stringify({
    toWho: "PlayerName", toWhoId: 123456,
    responsibleId: 789, responsibleUsername: "Admin",
    reason: "Swearing / Insults"
  })
});
const { caseId } = await warnRes.json();

// Fetch all warns for a player
const warns = await fetch(`/api/punishments/warns/123456`, {
  headers: { "Authorization": "Bearer TOKEN" }
}).then(r => r.json());

Rate Limits

All command endpoints share a general request limit, plus a couple of narrower cooldowns on specific actions.

ScopeLimitOn exceed
Per IP (general)45 requests / 10 seconds429 Rate limit exceeded
Duty shift actions1 action / 2 seconds429 with remainingMs
API Key regeneration1 / 15 minutes (per server)429 with remainingSeconds

Backoff guidance: on a 429, stop retrying immediately — back off for at least the window above before trying again (use remainingMs/remainingSeconds when the response includes one). Don't poll faster than once every couple of seconds for anything other than heartbeat, which already runs on its own fixed interval.
