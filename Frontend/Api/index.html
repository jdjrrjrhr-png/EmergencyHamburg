What you can do

The platform gives authorized staff real-time visibility and control over any live Emergency Hamburg server.

Player management

Kick, ban, freeze, warn, bring, or teleport to any player in any live server you moderate.

Top-down map

See every player's position overlaid on the game map with team colors and real-time streaming.

Audit logs

Every punishment, join, leave, robbery, and team change is captured with full context and timestamps.

Session admin chat

All staff in the same server dashboard share a live ephemeral chat, complete with system action messages.

Remote bans

Issue bans and warns from the API or dashboard; they persist across server instances via DataStore sync.

Discord integration

All high-level audit events (bans, kicks, warns, shutdowns) are forwarded to your Discord webhook automatically.
